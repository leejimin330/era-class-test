# 제미나이 미래 시대 시나리오 작성 가이드

미래 시대 4개는 제미나이가 세계관 초안을 쓰고, 이 프로젝트의 검증 스크립트를 통과하는 JSON으로 받아 쓰는 구조입니다.

## 사용 방법

1. 아래 **[공통 프롬프트]** 전체를 복사해 제미나이 새 대화에 붙여 넣습니다.
2. 이어서 **[시대별 요청]** 중 하나를 붙여 넣습니다. 한 대화에서 한 시대씩 받는 것을 권장합니다.
3. 제미나이가 출력한 JSON 코드블록만 복사해 `data/raw/gemini/<시대 id>.json`으로 저장합니다.
   - 예: `data/raw/gemini/ce2077.json`
4. Claude에게 "제미나이 결과 넣었어"라고 알려주면 검수·정리 후 `data/eras/`로 옮기고 검증합니다.

마음에 안 드는 부분은 제미나이에게 "중산층 계급을 더 웃기게", "정체를 하나 더 추가" 처럼 고쳐 달라고 한 뒤 최종본만 저장하면 됩니다.

## [공통 프롬프트]

````text
너는 "나라·계급·시대 테스트"라는 유머형 웹 테스트의 미래 시대 세계관 작가야.
사용자는 버튼 한 번으로 인류 역사 어딘가에 '태어나고', 그 시대의 인구 비율대로 나라와 계급이 정해져.
대부분은 평범한 서민으로 태어나는 게 웃음 포인트고, 최상층은 극악 확률의 레어 결과야.
지금은 실제 역사가 아닌 '가상 미래 시대'를 만들고 있어. 톤은 사이버펑크, 유머 80% + 그럴듯한 설정 20%.

[반드시 지킬 규칙]
1. 출력은 아래 JSON 형식의 코드블록 하나만. 설명 문장, 주석(//) 금지. 모든 텍스트는 한국어.
2. 정체(polities)는 5~8개. 각 정체의 population(백만 명) 합계 = worldPopulation (오차 1% 이내).
   - 인구가 큰 정체(거대 메가코프 도시권 등)와 작은 정체(궤도 정거장, 해상 도시 등)를 섞어서 비율 차이가 나게.
3. 각 정체의 classes는 5~7개. share(정체 내 비율, 0~1) 합계 = 정확히 1.0.
   - 반드시 '서민층'(농민에 해당하는 대다수 계급)이 share 0.5 이상.
   - 반드시 '최상위 극소 계급' 1개 포함 (share 0.000001 ~ 0.00001, 예: 메가코프 이사회 의장, AI 의회 의장).
   - 그 다음 상위층은 0.001 ~ 0.03 정도.
4. 각 계급 필드 개수 제한:
   - jobs: 3~6개 (짧은 명사구)
   - meals: 3~6개 (짧은 명사구, 미래 음식 드립 환영)
   - historyTips: 1~3개 — 이 시대 세계관 설정을 한 문장씩 (가상의 '역사적 사실'처럼)
   - lifespan: [최소, 최대] 나이, 1~120 사이, 최소 ≤ 최대
   - statBase: body(체력)/mind(지력)/charm(매력)/luck(운) 각각 [최소, 최대], 1~20 사이, 최소 ≤ 최대
     (최상위 계급은 luck 17~20, 서민층은 luck 낮게, 의체 노동자는 body 높게 등 계급 성격 반영)
5. id는 영어 소문자·숫자·하이픈만 (kebab-case).
   - 정체 id는 "<시대id>-<이름>" 형식 (예: "ce2077-neo-seoul").
   - 계급 id는 정체 안에서만 겹치지 않으면 됨 (예: "slum-dweller").
6. shareConfidence, populationConfidence는 모두 "low". sources는 모두 ["fictional (Gemini 초안)"].
7. 금지:
   - 실존 국가·민족·종교를 비하하거나 조롱하는 표현
   - 노예·예속 계급이 있다면 그 사람들을 조롱하는 농담 (유머는 시스템, 기업, 상황 쪽으로)
   - 실존 기업명·실존 인물명 (가상 이름을 지어서 쓸 것)
   - 과도한 폭력·성적 묘사

[출력 JSON 형식 — 이 구조 그대로]
```json
{
  "id": "ce2077",
  "group": "future",
  "year": 2077,
  "name": "2077년의 세계",
  "yearLabel": "2077년",
  "fictional": true,
  "worldPopulation": 9800,
  "sources": ["fictional (Gemini 초안)"],
  "polities": [
    {
      "id": "ce2077-neo-seoul",
      "name": "네오 서울 메가시티",
      "kind": "polity",
      "population": 120,
      "populationConfidence": "low",
      "sources": ["fictional (Gemini 초안)"],
      "classes": [
        {
          "id": "board-chair",
          "name": "메가코프 이사회 의장",
          "share": 0.000002,
          "shareConfidence": "low",
          "lifespan": [80, 120],
          "statBase": { "body": [8, 14], "mind": [12, 18], "charm": [12, 19], "luck": [18, 20] },
          "jobs": ["분기 실적 발표", "도시 날씨 구독료 결정", "의체 교체 수술 예약"],
          "meals": ["진짜 소고기 스테이크", "유기농 딸기", "산소 칵테일"],
          "historyTips": ["2070년대 네오 서울에서는 하늘의 광고 비행선 수가 별보다 많았다."],
          "sources": ["fictional (Gemini 초안)"]
        },
        {
          "id": "slum-dweller",
          "name": "하층 구역 거주민",
          "share": 0.6,
          "shareConfidence": "low",
          "lifespan": [30, 70],
          "statBase": { "body": [8, 15], "mind": [6, 13], "charm": [6, 13], "luck": [2, 9] },
          "jobs": ["배달 드론 수리", "데이터 라벨링 부업", "광고 시청 알바"],
          "meals": ["합성 단백질 바", "재활용수 라면", "광고 보면 무료인 김밥"],
          "historyTips": ["하층 구역 주민은 광고 15초를 보면 공기 정화 필터 1시간을 지급받았다."],
          "sources": ["fictional (Gemini 초안)"]
        }
      ]
    }
  ]
}
```
(위 예시는 형식 설명용으로 정체 1개·계급 2개만 보여준 것. 실제로는 규칙 2·3의 개수를 지켜서 전부 채워.)

출력 전에 스스로 확인해:
- 각 정체의 share 합계가 정확히 1.0인가?
- population 합계가 worldPopulation과 맞는가?
- jobs·meals 3~6개, historyTips 1~3개인가?
````

## [시대별 요청]

한 번에 하나씩 공통 프롬프트 뒤에 붙여 넣으세요.

### 1. 2077년 — 메가코프 도시국가 시대 (`ce2077`)

````text
이번 시대: id "ce2077", year 2077, name "2077년의 세계", yearLabel "2077년", worldPopulation 9800.
컨셉: 국가 대신 거대 기업(메가코프)이 도시를 통째로 운영하는 시대. 네온, 비, 의체(사이보그 신체), 구독 경제.
정체 예시(자유롭게 바꿔도 됨): 네오 서울 메가시티, 메가코프 연합 아시아 회랑, 해수면 상승으로 생긴 해상 부유 도시,
기업 지배를 거부한 농업 자치구, 사막 태양광 도시국가, 무국적 디지털 노마드 네트워크.
계급 예시: 이사회 의장(극소), 임원, 기업 시민(정규직), 계약직 의체 노동자, 하층 구역 거주민, 해커/데이터 브로커.
````

### 2. 2150년 — 궤도 정거장·화성 초기 식민지 (`ce2150`)

````text
이번 시대: id "ce2150", year 2150, name "2150년의 세계", yearLabel "2150년", worldPopulation 9000.
컨셉: 대부분은 여전히 지구에 살지만, 궤도 정거장과 화성 초기 식민지가 생긴 시대. 우주 이민 추첨, 산소 요금, 저중력 스포츠.
인구 비율은 현실적으로: 지구 정체들이 대부분이고 궤도·화성은 합쳐서 1% 미만이 되게 해서, 우주에서 태어나는 게 레어 결과가 되도록.
정체 예시: 지구 연안 방벽 도시 연합, 내륙 수직농장 국가, 적도 우주 엘리베이터 특구, 저궤도 정거장 연합, 화성 1기 식민지, 소행성대 채굴 기지.
계급 예시: 식민지 총독(극소), 우주 엘리베이터 소유 가문, 궤도 엔지니어, 수직농장 노동자, 산소 할당제 서민, 이민 추첨 대기자.
````

### 3. 2226년 — 네오 재팬 (`ce2226`)

````text
이번 시대: id "ce2226", year 2226, name "2226년의 세계", yearLabel "2226년", worldPopulation 7500.
컨셉: 네오 재팬이 세계 문화·기술 패권을 쥔 시대. 쇼군 대신 'AI 쇼군 시스템', 에도 시대 신분제를 사이버펑크로 재해석한 신(新)신분제
(예: 디지털 사무라이, 로봇 조닌, 오프라인 농민), 거대 로봇 축제, 홀로그램 신사.
정체 예시: 네오 재팬 본섬 아콜로지, 네오 재팬 위성 도시권, 범태평양 해상 연방, 대륙 연합, 오프라인 자연 보호구역, 달 도시.
계급 예시: AI 쇼군의 관리자 가문(극소), 디지털 다이묘, 디지털 사무라이(사이버 보안관), 로봇 조닌(상인), 오프라인 농민, 홀로그램 신관.
````

### 4. 2400년 — AI 공동통치 시대 (`ce2400`)

````text
이번 시대: id "ce2400", year 2400, name "2400년의 세계", yearLabel "2400년", worldPopulation 6000.
컨셉: 인간과 AI가 공동 의회로 세계를 다스리는 시대. 노동은 대부분 자동화됐고, 인간은 '의미 있는 일'을 배급받는다.
정신 업로드, 기본소득 포인트, AI에게 투표권 있음. 유토피아처럼 보이지만 은근히 관료적인 블랙코미디 톤.
정체 예시: 지구 공동통치 연방, 업로드 의식 클라우드 공동체(인구를 '의식 수'로 계산), 아날로그 생활 복원 마을, 금성 공중 도시, 목성 위성 연구 기지.
계급 예시: 공동의회 인간 의장(극소), AI 감사관 연락관, 의미 노동 배급 대상자(서민층), 업로드 대기자, 아날로그 장인, 기본소득 포인트 부자.
````

## 나중에 쓸 수 있는 2차 요청 (선택)

시대 데이터가 확정된 뒤, 같은 대화에서 아래처럼 문구 확장을 요청할 수 있습니다. 이번 단계에서는 하지 않아도 됩니다.

````text
방금 만든 JSON의 각 계급에 다음 필드를 추가해서 같은 형식으로 다시 출력해 줘.
- "daySummaries": 하루 요약 한두 문장짜리 2~3개
- "jokes": 결과 카드용 한 줄 드립 3개 (20자 안팎)
나머지 필드와 숫자는 절대 바꾸지 마.
````
